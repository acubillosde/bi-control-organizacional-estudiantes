# Casos de discusión

Las guías **no reproducen** el texto de los casos ni de los artículos, que tienen derechos de autor. La excepción es el caso ficticio de la Distribuidora Andina, que está escrito para este curso y se incluye completo. Cada estudiante consigue el material en la Biblioteca de la Universidad Externado o por los canales que indique el docente.

## Formato de exposición y réplica
- **Equipo expositor (15'):** contexto, problema de decisión, análisis con un marco del curso, recomendación y lección para el control organizacional.
- **Equipo de réplica (7'):** dos fortalezas, dos debilidades del análisis y una pregunta crítica.
- **Plenaria (8'):** moderada por el docente.
- Rúbrica: [R5](../evaluacion/rubricas.md#r5-exposición-o-réplica-de-caso).

## Capa de enseñanza de COAGUA
Cada guía de un caso con texto ajeno o con una entidad real termina con una **capa de enseñanza** propia del curso, ficticia y ambientada en COAGUA: una escena, dos roles que chocan, tres opciones con consecuencias, microescenas, un producto del equipo, una guía de evaluación y dos futuros. Sirve para el momento de «lección para COAGUA» sin atribuir nada a las organizaciones reales. El caso de la Profundización B es una narrativa completa: [Almacenes Mirador](caso_mirador.md).
