## Formato de exposición y réplica
- **Equipo expositor (15'):** contexto, problema de decisión, análisis con un marco del curso, recomendación y lección para el control organizacional.
- **Equipo de réplica (7'):** dos fortalezas, dos debilidades del análisis y una pregunta crítica.
- **Plenaria (8'):** moderada por el docente.
- Rúbrica: [R5](../evaluacion/rubricas.md#r5-exposición-o-réplica-de-caso).
