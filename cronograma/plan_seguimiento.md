# Plan de seguimiento docente

- **Canal principal:** *Issues* del repositorio `bi-control-organizacional-estudiantes`, con las etiquetas `duda-contenido`, `duda-powerbi`, `duda-entrega` y `error-en-material`. Las respuestas quedan visibles para todo el grupo.
