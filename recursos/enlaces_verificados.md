# Enlaces verificados

**Fecha de verificación:** 27 de octubre de 2026.
**Método:** solicitud HTTP con seguimiento de redirecciones (`curl -L` con agente de navegador) y búsqueda web para confirmar la existencia de las obras.
**Limpieza aplicada:** se unieron las URL partidas por saltos de línea, se eliminaron espacios y el código de formato institucional que aparecía pegado en algunas, y se retiraron los fragmentos `#:~:text=`.

**Estados**
- **Vigente:** respuesta 200 en la URL original.
- **Redirigido:** responde, pero en otra URL. Se indica el destino.
- **Caído:** 404 o 410.
- **No verificable:** el sitio bloquea el acceso automático (403) o no respondió. No significa que esté caído.
